Zero Gap Agent — Completeness Check Operating Procedure
How the Zero Gap Agent checks initial long-term care applications for missing information before the formal medical assessment — NordCare Pflegekasse, Long-Term Care Claims Operations
1. Purpose
This procedure defines how the Zero Gap Agent scans initial applications for long-term care benefits (Antrag auf Leistungen der Pflegeversicherung, object “Care Application”) and flags missing legal or personal parameters before the formal medical assessment is scheduled. The agent does not deny an application because details are missing. Its role is to halt the pipeline and flag the file for a quick data-gathering workflow, so that the strict 25-working-day window can be met.
2. Scope
Applies to initial Pflegeversicherung (long-term care insurance) benefit application intake only.
Completeness of Objection cases is out of scope for this demo.
The agent performs the completeness check on the Document object, but ingests the case-level timestamp (the initial “formless Antrag” date) to calculate SLA risk and track the days remaining on the statutory clock.
Primary inputs: official multi-page PDF/scanned application forms, formal representation authorizations (Vollmacht), and supplementary clinical logs.
3. Mandatory Fields & Validation Rules
The agent verifies the presence of the following critical sections of the application form under German social security standards.
Form section
Required fields
Rule / result if not met
1. Applicant Data
Full name, date of birth, insurance number (Versichertennummer), current address.
Hard failure if the insurance number is missing or mismatched, or if basic identity does not match. This prevents eligibility routing.
2. Legal Representation
Representative name and contact; legal guardian (Betreuer) checkbox; authorized representative / proxy (Bevollmächtigter) checkbox.
Conditional: if “yes” is checked, a matching power of attorney or court decree (Vorsorgevollmacht / Betreuungsausweis) must be attached.
3. Type of Benefit
At least one selected: care allowance (Pflegegeld), non-cash care benefits (Pflegesachleistung), combination benefit (Kombinationsleistung), fully inpatient care (Vollstationäre Pflege).
No selection: soft warning for the 3-day MD commissioning deadline; hard failure (drafted outreach letter) for the final 25-day decision phase.
4. Medical Contacts
Name and address of the general practitioner (Hausarzt); treaters/specialists optional but strongly preferred.
If blank, flagged as a soft warning, not a hard failure. The insurer needs these contacts to request medical history before the assessment.
5. Care Providers
Contact details of the family caregiver, or of the outpatient care service (Ambulanter Pflegedienst).
Mandatory only if Pflegegeld, Pflegesachleistung or Kombinationsleistung is selected.
6. Execution
Date, location, and signature (wet or digital).
Hard failure if unsigned. Unsigned forms cannot legally initiate processing.
7. SLA Triggers
Accelerated statutory deadline triggers, e.g. hospitalization, inpatient rehab, family care leave (checkboxes or keywords).
If detected, the agent overrides the standard 25-day clock and tags the case “Urgent SLA: 5-Day/10-Day”.
8. Civil Servant (Beamter)
Civil service subsidy office (Beihilfestelle) checkbox.
For civil servant applications, the checkbox must be verified so that cost-splitting is configured correctly.
Happy-path checks are hardcoded in the agent prompt. Edge cases (missing documents, civil service, power-of-attorney mismatch, benefit-type conditional logic) are pulled live from ARIS via MCP. Completeness rules are maintained as one SOP-style policy document per benefit type (e.g. “Completeness Policy: Pflegegeld v1.2”), written in insurer voice, listing required fields, legal basis and escalation rule, and stored as an ARIS-attached satellite document.
4. Completeness Check Procedure
The check fires on the document ingestion event.
The agent timestamps the case from first applicant contact (the “formless Antrag” date), separately from when it runs the completeness check. The 25-working-day statutory clock starts at first contact, independent of when the document arrives.
The agent links the document to the case. It matches by insurance number (Versichertennummer) if present; otherwise it uses a probabilistic match on name + date of birth + date of application. Every non-exact match is flagged “assumed link — no primary key”.
The agent scans for accelerated statutory deadline triggers (Section 3, row 7). If detected, it overrides the standard 25-day clock and tags the case “Urgent SLA: 5-Day/10-Day”.
The agent validates each form section against Section 3, including the Beihilfestelle check for civil servant applications, and records every hard failure and soft warning.
If a care diary (Pflegetagebuch) or hospital discharge report (Entlassungsbericht) is present, the agent catalogs it as a verified attachment and ties it to the case file for the medical appraiser — only if an exact primary key match exists. If the case link is an “assumed link” (probabilistic match), these medical documents are strictly quarantined for human verification.
The agent calculates SLA risk and the days remaining on the statutory clock from the case-level timestamp.
The agent returns a binary result — “Ready for Assessment” or “Missing Information” — with a structured list of the specific missing or failed fields.
5. Missing-Information Handling
Escalation branch: If information is missing, the agent may escalate to the case manager with a plain-language summary of the gap.
Outreach branch: Alternatively, the agent drafts an outreach letter to the applicant requesting the missing item(s).
All drafted outreach letters and case manager escalations are placed in the human-in-the-loop queue, each visibly tagged with a dynamic countdown timer (“Days to SLA Breach”), so that caseworkers prioritize requests that pause the penalty clock.
No outbound communication (letter or escalation) leaves the system without human review and sign-off. There is no auto-send under any condition.
All agent outputs (flags, notifications, drafted letters) are issued in German.
6. Roles
Zero Gap Agent: runs the completeness check on ingested documents, links documents to cases, detects SLA triggers, returns the binary result, and drafts outreach letters or escalations for human review.
Caseworker: reviews and signs off drafted letters and escalations in the human-in-the-loop queue, prioritizing by the “Days to SLA Breach” countdown.
Case Manager: receives agent escalations with a plain-language summary of the gap.
Human verifier: verifies care diaries and discharge reports quarantined because of an assumed case link.
Medical appraiser: receives the verified attachments tied to the case file.
7. Escalation
When information is missing, the agent may escalate to the case manager with a plain-language summary of the gap, as an alternative to drafting an outreach letter. Escalations follow the same rules as letters: they are placed in the human-in-the-loop queue with the “Days to SLA Breach” countdown and require human review and sign-off before leaving the system. Medical documents linked through an “assumed link” are quarantined for human verification rather than cataloged.
8. Agent Output & Closure Criteria
Binary result recorded: “Ready for Assessment” or “Missing Information”.
Structured list of the specific missing or failed fields.
Case timestamp from first applicant contact and days remaining on the statutory clock.
Deadline tag: standard 25-day clock, or “Urgent SLA: 5-Day/10-Day”.
Case-link status: exact match on insurance number, or “assumed link — no primary key”.
Attachment status: care diary / discharge report cataloged as verified, or quarantined for human verification.
Every outbound letter or escalation carries human sign-off before it leaves the system.
9. Legal & Local Rules Applied
“Formless Antrag” precedent: In Germany, a care application is legally valid from the day a single sentence requesting care is received, even by phone or email.
Statutory clocks: 25-working-day statutory window, starting at first applicant contact; 3-day deadline for commissioning the Medical Service (MD).
Accelerated deadlines: hospitalization, inpatient rehab or family care leave triggers override the standard 25-day clock with a 5-day or 10-day deadline.
Validity of the application: unsigned forms cannot legally initiate processing; without a selected benefit type, the application cannot be legally prioritized or calculated.
Civil servants: civil servant (Beamter) applications require the Beihilfestelle checkbox for correct cost-splitting.
